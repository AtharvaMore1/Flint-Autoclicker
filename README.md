# FlintAutoClicker

A Windows autoclicker and macro recorder with a clean, customizable interface.

## Features

### Autoclicker

- Mouse clicks or custom keyboard input.
- Adjustable intervals and random timing offsets.
- Continuous clicking or a set click count.
- Fixed click locations with a screen picker.
- Toggle or hold-to-click hotkeys.

### Macros

- Record and replay mouse buttons, keyboard inputs, and scrolling.
- Build and edit sequences with clicks, key presses, holds, scrolls, and waits.
- Continuous playback or a set number of loops.
- Adjustable playback speed and pauses between loops.
- Save/load macros, multi-select editing, and undo/redo.

### Interface

- Light and dark themes.
- Remembered settings and macro drafts.

Interface icons by [Phosphor Icons](https://phosphoricons.com/), used under the MIT license.
